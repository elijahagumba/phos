# ADR 0061 — Clock A public core is published; partner and product surface stay unearned

- **Status:** Accepted
- **Date:** 2026-08-23
- **PART:** Category programme Sessions Ω1–Ω2 (Clock A close)
- **Supersedes:** nothing
- **Depends on:** [ADR 0049](0049-split-scorecard-public-files-vs-partner.md)

## Context

Clock A is the public mathematical core. Clock B needs a design partner. Ω3
(Intelligence / API / UI) is last and only to render already-earned narratives.

## Decision

1. **Ω1.** `observations_under` is the reconstructability audit: narrative →
   evidence → joint/dynamical deviation or stamped fact → observation ids.
2. **Ω2.** Negatives keep the same status as positives in encyclopedia, easy to
   reads, and README: 18.72, 8.6× not 10×, CERT 6B 0.104, `:precision` loss,
   command 0/16 and 1/4 unpooled, distillation louder not quieter, Data4Cyber
   ruler refused, S7 unlabelled, 3W faults, no labelled command corpus.
3. **P1–P3 and Ω3** stay blocked. No TAP in `src/phos`. No FastAPI. No UI.

## Consequences

- Tracker `current_session` is **P1**. Next action is a human partner
  conversation, not Intelligence. Category claim is not earned.
