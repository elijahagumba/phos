# ADR 0331 — The public page is set for both themes, and the hero is the page

- **Status:** Accepted
- **Date:** 2026-10-26
- **PART:** the public record
- **Supersedes:** nothing
- **Depends on:** [ADR 0330](0330-the-public-plates-are-one-canvas-and-the-poster-carries-one-sentence.md),
  [ADR 0200](0200-the-public-repository-takes-the-house-style.md),
  [ADR 0317](0317-a-slot-exists-only-when-a-declared-law-is-false.md)

## Context

ADR 0330 put every plate on one canvas. Three things were still wrong with the
public front page.

**It was set for one theme.** Every plate is jet black. A reader on GitHub's
light theme met a column of black slabs on white, which no part of the page was
designed for. GitHub renders `<picture>` with `prefers-color-scheme`, so the
medium has supported two themes all along.

**The opener stated the claim and did not show it.** The poster says security
that tells you what it doesn't know. The thing that makes that true — a shift
page with eight slots, most of them empty — was described in prose further down
and never shown. The most arresting fact about this product is that its screen
is mostly blank on purpose, and the front page was hiding it.

**Every plate carried the whole alphabet.** An SVG in an `<img>` cannot fetch a
font, so each plate embeds Inter. Each was carrying all of Latin, about 95 KiB,
to set perhaps sixty distinct letters.

No measurement is in this record. No corpus was generated or scored.
`eval_runs/log.jsonl` was not appended. Held-out data was not opened. No
published figure moved. v1 stays 8 of 12. P1 stays blocked.

ADR 0330 is in the same working tree, so this record takes **0331** and note
**128** (ADR 0292).

## Decision

**A plate is drawn once in tokens and resolved per theme. The first plate is the
operator page, rendered by the code that makes it.**

Colour is a token — `@plate`, `@strong`, `@body`, `@muted`, `@blue`,
`@hairline`, `@edge`, and `@logo` for the wordmark. A card never knows which
theme it is being built for; `Theme.resolve` replaces the tokens in the finished
document. Both themes are written for every plate, and the README places each in
a `<picture>` with a `prefers-color-scheme` source. The light theme is not an
inversion: `#8E8E93` is a quiet grey on black and an illegible one on white, so
each ink is chosen again. Every plate gains a one-pixel edge, because a white
plate on GitHub's white canvas has no boundary otherwise.

Plate **01** is the page. `shift_page_card` builds a hand-built inlet — six
declared laws, one unbooked download, a write from a station the plant named,
no controller sample — and draws what `assess_plant` and `law_page` return for
it. The one taken slot, its time, its cited sentence, the four held laws and the
one unstated law are all read off that return value. The seven empty rows are
the seven slots the page did not fill. Nothing on the plate is typed out by
hand, and the plate says on its face, and in its alt text, that it is a fixture
and not a plant, a measurement, or a detection claim.

Every plate header sits on one grid: the label on 44, the first title line on
84, the second on 116. Each plate embeds only the glyphs it sets, which takes a
plate from about 99 KiB to about 28 KiB.

**Motion is refused.** Whether an animated SVG survives GitHub's proxy is not
documented, and it cannot be established without publishing one. A front page
for a product whose claim is silence should also not move. This is a refusal,
not an omission.

### Options

1. Keep one theme and accept the light-mode page. The reader did not choose the
   theme to be shown something nobody designed. Refused.
2. Draw each theme separately. Two drawings drift, and the drift is invisible
   until someone switches theme. Refused.
3. Draw once in tokens, resolve per theme, and make the first plate the real
   page. Chosen. No number moves.

## Consequences

**Gained.** The page is set for whichever theme the reader brought. The opening
plate is the product rather than a picture of it, and it cannot say something
the code does not return. A visitor downloads roughly 270 KiB of plates instead
of roughly 700 KiB.

**Cost.** Twenty plate files instead of ten. The wordmark is still a PNG, and it
is most of what the poster weighs. This record adds no measurement and moves no
number. v1 stays 8 of 12. P1 stays a human conversation.

**Ten years.** The front page is generated by the thing it describes. A change
that makes the page lie about the engine cannot be made in the README; it has to
be made in the engine, where the tests are.

## What would reverse this

A plate that exists in only one theme. A hero that is a drawing of what the code
returns rather than the return value. A figure on that plate that did not come
from the code. Adding motion without a record that says what it is for. Putting
a score, a price, or a date for either on the front door.
