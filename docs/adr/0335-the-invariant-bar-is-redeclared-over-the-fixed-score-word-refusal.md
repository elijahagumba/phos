## Context

ADR 0333 declared `law-inlet:invariants` on `phos-icssim-dev` and pinned four files by sha256 at
tree `4dac107`. It was written on a branch `main` had not merged, and so was ADR 0329, which fixes
the score-word refusal so that the check reads the fact and not the law's name.

ADR 0329 changes `src/phos/atlas/declared_law.py`, which is one of ADR 0333's four pinned files. The
two records could not both be honoured: merging the fix makes the committed declaration describe code
that no longer exists, and the harness does not recompute those four digests itself, so nothing in
the run would have caught it. Scoring the unfixed tree would have produced a number about a
score-word refusal already judged wrong, and bar 2 is the score-word bar.

The order taken was: merge ADR 0333 (additive, no pinned file touched), merge ADR 0329, then write
this record. Both merges are in HEAD before any score runs. `uv run pytest -q` reports 4757 passed,
21 skipped, 45 deselected; `ruff check`, `ruff format --check` and `mypy` are clean.

**What this record may not do, and does not.** It does not move a bar. The eight counts below were
read out of ADR 0333's own file by the script that wrote this one, so a reword is not available as a
mistake. A declaration whose bars moved to meet a number would be the failure this programme exists
to prevent; only the digests and the tree move here, because only the code moved.

### Bars, not reworded

Each is a count over the whole corpus and each is met or not met. There is no tolerance and
no per-run exemption.

1. Placed sentences that do not begin with their law's name, a period and a space: **0**.
2. Placed sentences containing the word confidence, probability, weight, magnitude or score:
   **0**. The refusal is the word. A decimal the plant already uses is not a score-word.
3. Pages whose length exceeds `OPERATOR_PAGE_CEILING`: **0**.
4. Reports in which some law name in the register appears in more than one of held, broken
   and unstated, or in none of the three: **0**.
5. Reports with nine or more breaks whose placed page is not exactly the eight earliest by
   time, then by law name: **0**. The ninth break in time is absent, including when a person
   would have called it severe.
6. `LawBreak` subclass instances admitted to a page: **0**. Admission is
   `type(item) is LawBreak`, and a subclass is refused before the page is ordered.
7. Inlets built from a frame the dissector refused: **0**. A malformed frame becomes a
   `MalformedFrame`; `inlet_from_tables` raises on a non-empty `malformed` and returns no
   inlet, so no `LawBreak` can descend from one.
8. Empty-register reports returning anything other than three empty lists: **0**.

### Reported beside the bars, and not a bar

The run also reports the number of runs scored, the number of pages built, the distribution
of page lengths, and how many of the eight slots ordinary operation fills. Those are counts
for the verdict to quote. None of them is a threshold here, and none may be restated as a
detection rate, a false-alarm rate or a queue-ranking result.

### The fallback, declared now

**If ordinary operation fills the eight slots, the queue is unstaffable on this corpus, the
predicates stay exactly as written, and the verdict ADR says so.** That outcome is a result,
not a failure to produce one. It does not license retuning a predicate, widening an admission
rule, raising the ceiling, or adding a seventh law. The ceiling 8 moves only when a partner
names a different integer in a new record. `controller_valve`'s literals — close 0.0, open
1.0, release mode 3.0, belt past the filler 1.0 — are ICSSim's PLC1 numbers and are not
retuned onto another plant.

### What a break is, restated

Only a broken law is a `LawBreak`, and only that list enters the page. Held has no timestamp
and takes no slot. Unstated is the plant having named a law and supplied nothing that law can
be checked against; it is recorded once and is not dropped. **A break is a false law, not an
attack.** The page does not name the cause. An empty page is not a safe plant.

## Consequences

**Gained.** The score runs against the code that will ship, under a bar that was frozen before the
harness existed and is carried here byte for byte. The digest method is now checked rather than
asserted, because it reproduces ADR 0333's own combined figure from the pre-merge blobs. Two records
that could not both be honoured are reconciled in the open, with the order of the merges on the
record.

**Cost.** One more declaration, and a second record in the chain a reader must follow to see which
tree was scored. ADR 0333 keeps its number, its bars and its reasoning; only its digest set is
retired, and this record says so in its header rather than leaving a reader to diff two hashes.

**What this record contains.** No number. It opens no capture and no historian file, scores no
corpus, and does not append `eval_runs/log.jsonl`. The residual files stay on disk, unedited and
unimported. ADR 0316 stays the residual clock's outstanding score and is not run here.

v1 stays **8 of 12**, with A3, A7, S3 and C2 open. This declaration moves no criterion; the invariant
counts, when they exist, are structural and judge none of the four. The frozen measurements stay
frozen and unpooled. Synthetic-harness results are a simulated diagnosis and not a field rate
(ADR 0073), and no claim from this run may say the plant map improves detection on real plant data
(ADR 0143). No Intelligence, API, UI or TAP is started. P1 remains a blocked human conversation, and
this record does not unblock it.

**Before this reaches `main`.** ADR 0044 counts a decision record as an advancement, so the merge
carrying this one, ADR 0333 and ADR 0334 also moves `encyclopedia/`, `easy to reads/` and
`README.md`. ADR 0329's branch brought its own share of that; the other three have not.

## What would reverse this

Moving any of the eight bars, in this record or in a successor, so that a count can be met. Scoring a
tree whose four digests are not the ones above, or restating a digest without recomputing it by the
method ADR 0333 defined. Running the command more than once and reporting the better result. Opening
a held-out split, or reading a red-tier corpus, because the development corpus was inconvenient.
Retuning a predicate, widening an admission rule, raising `OPERATOR_PAGE_CEILING`, or adding a
seventh law because ordinary operation filled the page: the fallback above already names that outcome
as a result. Treating these structural counts as a detection rate, a false-alarm rate, a recall or a
queue-ranking result. Reading the merge of ADR 0329 as permission to keep editing pinned files
between a declaration and its score.
