# 119. The plan loads before anyone builds

*Both tools see the same lock. The plan is the sequence. ADR 0324.*

The operating plan is written down. A later session only follows it if the
session actually loads it. Cursor loads the rules in `.cursor/rules/`. Claude
Code does not read that folder, and it loads what `CLAUDE.md` imports.

The lock is one short rule. It points at the plan, and it says what a build
from that plan is not allowed to do. The residual detectors stay. The law
page does not import them. No new protocol arrives without a declaration. A
function code is not a station and not a program transfer. The page still
has no score. A break is not called an attack. An empty page is not called
a safe plant. Intelligence, an API, a screen, and a tap stay unbuilt. The
later quarters wait until the twelve-month gate is written down.

The rule lifts nothing else. The frozen numbers stay where they are.
Version 1 stays at eight of twelve. Nothing was scored. The plan is not a
result about a plant.

Building starts when a person asks. The first commit of that build is a
declaration of the inlet, and that declaration does not read a file.
