# 107. The transfer keeps its place

*Eight process hits were filling the page. The unbooked program change stays. ADR 0312.*

Four downloads, uploads, or online edits have no booking. The page of setpoint
hits is already full, eight handoffs. Those four program changes would have nowhere
to go.

They stay. The instruction is still go and look. Four of the handoffs leave so the
page stays at eight. The misses of the program changes go from four to none.

A booking that names both tags of a handoff, and covers that hour, takes that
handoff off the page. Both stories stay. Neither is chosen. A booking that names
only one tag leaves the alert up.

This is a made example, not a plant. Version 1 still stands at eight of twelve.
