# 109. The walk column is written down before it is scored

*The valve the plant's own controller would write. ADR 0314.*

One slow walk was missed, so the detector that was specified before that score is
allowed to exist. It watches one valve. When the tank is above its maximum, the
controller would close the inlet. When the tank is below its minimum, the
controller would open it, and that open value is the constant 1 copied from the
controller. Between the two, the column stays quiet, because the controller does
not move the valve there. Each sample stands on its own. Nothing is added up.

The column is in the code. It was scored later, and that score is note 110. The
sealed runs stay sealed. Version 1 still stands at eight of twelve.
