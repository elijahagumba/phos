# 61 — The next look is written down before it happens

Two HAI editions have been sitting on disk with a line in the table that says the
files are missing. The files are there. They have not been scored, because they are
the one clean look at the grouping rule.

That look is now a named command. It will score the same four detectors twice: once
as they already publish alarms, and once after the shared grouping rule. Nothing
else in the table is scored again. The first edition has 58 attacks. The second has
52. A summary page says 40 for one of the second edition's files; the labels
themselves have 38 stretches, and 38 is the number that will be used. The second
file's labels are lined up by row, because the clock text does not match.

The command has not been run.
