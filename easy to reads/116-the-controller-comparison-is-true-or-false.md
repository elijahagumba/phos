# 116. The controller comparison is true or false

*Agreement is silence. Disagreement is one break per side. Manual mode is unstated. ADR 0321.*

The plant's own controller already says what the two valves do when both
modes are release. The input valve closes when the level is strictly above
its maximum and opens when the level is strictly below its minimum. Inside
that band, including either end, that side does not break. The output valve
closes when the bottle is strictly above its maximum or the belt is strictly
past the filler, and opens otherwise. The closed value, the open value, the
belt distance, and the release mode are the plant's own constants. They are
not tuned. There is no divisor.

When the valve is the value that rule writes, the law is held and takes no
slot. When a side disagrees, that side is one break, at the sample time, and
the page names the valve and the value the rule required. Both sides can
break. That is two breaks. The law is not also held.

If no sample was supplied, the law is unstated. If either mode is not
release, the automatic law was not in force. That is unstated, not a break.
A valve held by hand is not this law's attack.

If the plant did not name this law, it appears on none of the lists. There
is no score. The old detector files are unchanged. Nothing was scored on a
plant. Version 1 still stands at eight of twelve. This page is not that
result.
