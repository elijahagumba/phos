# 94. The release note adds no measurement

*A one-page note for the public repository. The cards stay. ADR 0299.*

The public page already shows what PHOS measured, as a set of cards. Beside them there is now
a single page in sentences: how to run the demo, what the real testbed showed, what the engine
still cannot do, and which later attempts were kept or turned down. Every figure on it was
already in the record. The noncommercial licence is the same licence.

Three sentences drafted for the announcement had rounded a result toward the end that sounds
better. False alarms fell from 28 a day to somewhere between 20 and 24, which is not a flat
quarter. Attacks caught fell from 32 to somewhere between 23 and 25, which is not a flat nine.
Twenty-one more attacks, 32 to 53 of 70, is the count that had been written as 66 percent.
The four attempts are one that was kept, two that were turned down, and one that could not
be posed. They are not three gains thrown away. One command rebuilds four of the five
pinned records. An outsider has not run it, so that criterion stays open.

Nothing was measured. Version 1 still stands at eight of twelve. Putting the note on the
public site, and posting it, is a separate step.
