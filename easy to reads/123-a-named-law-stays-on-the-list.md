# 123. A named law stays on the list

*A score does not get onto the page. A law this page cannot check is still named. ADR 0326.*

The page can show eight broken laws. Each line names its law, then the fact.
The builder already refused a line that said confidence, probability, weight,
magnitude, or score. The page itself did not. A line someone built by hand,
with one of those words in it, could still take a slot.

That line is now refused before the page is ordered. The other lines in the
same call are not shown either. A number the plant already uses, with none
of those words beside it, still can.

A plant can name a law this page has no check for. That name used to
disappear. It is now listed as unstated. It takes no slot. An empty list of
laws still checks nothing.

Nothing was scored. Version 1 stays at eight of twelve. This is not a result
about a plant.
