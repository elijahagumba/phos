# 117. A slot enters only as a law break

*The exact type. A subclass that carries a magnitude is refused. ADR 0322.*

A slot may enter the operator page only as a law break, the exact type. A
subclass is a different type. One that adds a magnitude is refused, even
when its name is one the plant declared and its time is the earliest. It
raises, and it does not appear on the page.

Checking that the object is "a kind of" law break is not enough. A child
type can carry a number, and this page has no number. A real law break, the
type itself, still enters when its name is declared.

The order is still time, then the law name. The page still holds at most
eight. Held and unstated still take no slot. The report still reaches the
page only through the broken list.

No new law was added. No new threshold was added. There is no score. The
old detector files and the other page builders were not edited, and this
page does not import them. Nothing was scored on a plant. Version 1 still
stands at eight of twelve. This page is not that result.
