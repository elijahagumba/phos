# 74 — Which address, not which machine

Version 1 is now seven of its twelve tests.

The one that moved is Sentiel's "which, not just how many." Yesterday the list of
things it was allowed to notice was empty, so every answer was zero, and that was
not counted. Today the list is the organisation's own email directory: a thousand
addresses, taken from the staff list, written down before anyone looked at who the
insiders were. On both datasets the features then said which of those addresses a
person wrote to. On the small release, 310296 person-days named at least one. On
the larger release, which has 70 labelled insiders against the small release's 2,
292539 person-days did.

It still cannot say which website or which computer. The staff list has no column
for those, and they were not filled in from the activity logs. Four of the six
features stay at zero for that reason. This does not find more insiders. The test
that asks for more people stays failed: 1 against 59.

Five tests are still open. The queue is still 57 of 203. One command still cannot
rebuild the validation datasets. Nobody outside the project has rebuilt the
numbers. And the onboarding timer is still waiting on a person.
