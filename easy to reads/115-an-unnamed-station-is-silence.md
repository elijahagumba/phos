# 115. An unnamed station is silence

*Outside the declared set is one break. An empty set is unstated. ADR 0320.*

A plant may name the stations allowed to write. A write from a station
outside that set is one break, at the time of that write. A second station
outside the set is a second break. A station inside the set is silence for
this law. The law is held, and it takes no slot.

An empty allowed set means the directory was not stated. The law is unstated,
including when a write is present. An empty directory does not make every
station an intruder. If the plant did not name this law, it appears on none
of the lists.

A function code is not a station. The caller supplies the name. This law does
not read a learned graph, so it does not speak about a station the plant
named. There is no score. The old detector files are unchanged. Nothing was
scored on a plant. Version 1 still stands at eight of twelve. This page is
not that result.
