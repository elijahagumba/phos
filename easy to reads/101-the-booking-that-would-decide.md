# 101. The booking that would decide

*The page says which missing fact would take the alert down. ADR 0306.*

When a program change has no booking, the alert says go and look. It also names the
one thing that would withdraw it: a booking that names this act and covers this
hour. That sentence is not a probability.

Hand that booking in, and the alert comes down. Both stories stay. Neither is
chosen. The page does not become a verdict.
