# 189. The broken image nobody saw

The public record page — the one that lists every measurement this project has taken, including the
failures — had a broken image at the top of it. A grey box with alt text where a drawing should be.

It had been like that for nine commits. It was exported, pushed, and read by whoever opened that
page, and nobody noticed, including everyone who has reviewed the public repository since.

Here is how it happened. The drawings are generated by a script, and that script writes a file
called `record-plate.svg`. At some point the committed drawings were renamed by hand — `record.svg`,
`poster.svg`, and so on — and the script was not updated. The page kept pointing at the old name.
The file the page wanted no longer existed, and the file that did exist had no page pointing at it.

## Why nothing caught it

The export has a guard, and the guard is good at its job. Before anything is written to the public
repository it checks two things: that no forbidden file is leaving, and that no forbidden text is
leaving. A funding discussion, a home directory path, a private email address — those are stopped
dead, and one has been.

Both of those checks are about what must not get out. Neither of them asks whether what *does* get
out still works. The lab can link to a file the export does not carry, and that is fine inside the
lab. The export is the exact moment that stops being fine, which makes it the only sensible place
to check.

## What it checks now

Every relative link and every image in every exported page has to land on a file the export
actually carries. If one does not, the export refuses before writing a single byte, and names the
file, the line and the target. External links are not checked — that is the whole internet's
problem, not this script's.

Running it for the first time found six broken things, not one:

- The record page's missing drawing.
- A link on the front page written as `../../discussions`, which works in GitHub's web interface by
  accident of how it resolves addresses, and is not a path in the repository. It is now the URL.
- **Four decision records linking to other decision records by filenames nobody had read.** ADRs
  0395, 0397, 0398 and 0416 each cited a sibling record — the right number, with a title someone
  had guessed. All four numbers are real records under different titles. Only the link changed; not
  a word of any claim.

That last one is the find. These are the records this project points at as its evidence, and four
of their internal citations went nowhere.

## The other half: images with no page

The same pass lists images nothing points at. There were eighteen. That number is not the same as
"eighteen useless files", and the difference matters.

Three are the logos, carried for anyone who wants to cite this work. Four are measurement charts
whose records name them in prose — "the chart is `reliability-development.svg`" — which is a
citation, not a link. Two more were charts the shortened front page stopped showing, and those two
were deleted and then restored, because a test reads both of them value by value and checks each
number against the record it came from. Deleting them for being unreferenced turned the suite red
within a minute.

Nine were genuinely dead: drawings made for a long front page that no longer exists. Those are
gone, and the public repository is 920 KiB lighter.

So the check reports unreferenced images rather than refusing them, and a test names the nine that
are carried on purpose with the reason for each. A tenth one fails that test. Driving the number to
zero would have deleted evidence.

## What is still wrong

The script that draws the plates still writes the old names. It needs a font library this machine
does not have, so its output could not be compared against what is committed, and guessing which
drawing belongs under which name would be worse than leaving the drift in place. Running that
script is therefore not a harmless act: it will drop eight wrongly-named cards into the overlay.
The test above is what will say so, loudly, which is the best that can be done without the font
library.

## The lesson, if there is one

The guard on that door was built to stop secrets getting out, and it does. It was never asked
whether the thing it let through was any good. Two different questions, and only one of them had
a check.

Nothing was measured here. No bar moved. The scoreboard still reads eight of twelve.
