# Sentiel routing is written; the partner is the next gate

**What this is:** Sessions S1–S5 and the Clock A close (Ω1–Ω2). Sentiel now has
an executable rule that a 180-person CERT role is not a peer group, a declared
counterparty directory (missing means insufficient, not a graph embedding), a
pinned CERT budget curve, and an empty HR-ticket inlet. Atlas narratives walk
to observation ids. The public record keeps the same negatives it already had.

**Why it exists:** Peer advantage is retired (zero labelled peer-relative
positives). CERT at 48 alerts is still 10.4% precision, 0.5 recall. 30–50
tickets a day is an estate conversation. Intelligence does not create a
manifold.

## What changed

Routing lives in a *new* module so the 6B spine (`peers.py`) stays frozen.
Default peer policy still allows size 180 — the rule is opt-in honesty, not a
rewrite of the public row.

Unusual is still not a why: a thin self-history departure can lead with
`insufficient_evidence` while losers stay listed. Hypothesis confidence stays
unset.

Clock A is published as a public mathematical core. Tracker live session is
**P1**, blocked on a human design partner. Ω3 (Intelligence / API / UI) stays
unearned.

## What this is not

Not a revived peer claim. Not 30–50 earned on CERT. Not FastAPI. Not a live
plant. Not ≥70% command lead. Not 10× on every dataset. Not 2–3 Atlas pages a
day.
