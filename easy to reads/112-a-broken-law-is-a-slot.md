# 112. A broken law is a slot

*The page shows a law the facts make false. ADR 0317.*

A slot exists only when a law the plant or the operator already declared is
false. A law the facts satisfy is silence. The time of the broken fact puts
the slots in order. The size of a leftover does not open a slot, and it does
not move one in front of another.

One setpoint written inside the ordinary band is silence. Two tags written
inside that band, inside the window the plant already uses, are one slot, at
the first write. A walk one step short of the length already fixed is
silence. A walk that meets that length is one slot, at the first step. A
download, an upload, or an online edit with nothing booked over it is one
slot. The same act with a booking that covers it is silence. A handoff is a
slot while no booking names both tags. A booking that names both tags is
silence. A register function code is still not an act.

Eight is the ceiling already fixed for a shift. It is not searched. When
fewer laws are broken, the page is already complete. When nine are broken,
the eight earliest stay. A later fact that the old ranking would have put
first is the one left off.

The old detector files are unchanged. Nothing was scored on a plant.
Version 1 still stands at eight of twelve. This page is not that result.
