# Dynamics are an experiment; switching can starve

**What this is:** Sessions C5–C8. Beside snapshot Mahalanobis there is now a
named linear dynamical residual (`atlas-var1`). Declared modes that are too
rare fall back to the pooled model. An attacker who writes a *valid* other
phase whose physics match that phase is still **unhandled**.

**Why it exists:** A snapshot scores a moment without yesterday. A batch column
is not that plant. Lookup-by-recipe-step is not a switching system, and sparse
steps already exploded false alarms (note 20).

## What changed

A VAR with a declared lag fits only on attack-free train and scores the
one-step residual. Dummy-batch pooled snapshot stays blind; declared
phase-conditional snapshot can still recover that fixture. Mixed-mode VAR is
not the public distillation row. `dwell_samples` stayed 1.

Starved phases are listed, not silently "learned." Forgery that lands in the
wrong \(f_m\) is flagged by mismatch. Matching-physics forgery is named as a
gap.

## What this is not

Not 2–3/day. Not a security claim against a lying PLC. Not clustering a phase
from correlations as the public row. Not `torch`. HAI three-way later measured
`atlas-var1` at **14071.07** FP/hour (ADR 0064); that is louder than snapshot
Mahalanobis and is refused as the public detector.

The decisions are [ADR 0054](../docs/adr/0054-var-residual-is-a-named-experiment.md)
and [ADR 0055](../docs/adr/0055-starved-modes-fall-back-forgery-unhandled.md).
HAI measurement: [ADR 0064](../docs/adr/0064-var1-on-hai-is-louder-than-snapshot-mahalanobis.md).
